Ch.1 Les Structures de Données
1.1

Constantes et Variables

Constante
Valeur fixe pendant toute l'exécution. Caractérisée par son nom et sa valeur.
# Exemples PI = 3.14 G = 9.8
Variable
Valeur modifiable pendant l'exécution. Caractérisée par son nom, son type et son contenu.
# Affectation A = 5 # A ← 5 B = 10 # B ← 10
⚠ Piège courant : Pour permuter A et B, il faut une variable temporaire AUX. Sans AUX, l'une des valeurs est écrasée !

Algo

Python
Variable = valeur

Algo

Python

Règle : La valeur à droite du ← doit être compatible avec le type de la variable à gauche.

Ch.3 Les Structures Conditionnelles
3.1

Trois formes de conditions

Forme réduite

# Algo SI condition ALORS Traitement FINSI # Python if condition: traitement

Forme complète

# Algo SI cond ALORS Traitement1 SINON Traitement2 FINSI # Python if cond: traitement1 else: traitement2

Forme généralisée

# Python if cond1: traitement1 elif cond2: traitement2 elif cond3: traitement3 else: traitementN
Choix multiple (SELON / match)
# Algo SELON S 1 : Traitement1 2,3 : Traitement2 4..6 : Traitement3 SINON: TraitementN FINSELON # Python match S: case 1: traitement1 case 2 | 3: traitement2 case _: traitementN
Exemple : bulletin de notes
if moy >= 18: print("Excellent") elif moy >= 16: print("Très bien") elif moy >= 14: print("Bien") elif moy >= 12: print("Assez bien") elif moy >= 10: print("Passable") else: print("Redouble")
Astuce : Toujours tester du plus grand au plus petit (ou inversement) pour éviter les erreurs de recoupement.
Ch.4 Les Structures Itératives (Boucles)
4.1

Les trois boucles

POUR nombre connu

# Algo Pour i de Vi à Vf faire Traitement FinPour # Python for i in range(Vi, Vf, pas): traitement
Vf est exclu en Python. Ex: range(1,6) → 1,2,3,4,5

TANT QUE 0 fois ou +

# Algo TantQue cond Faire Traitement FinTantQue # Python while cond: traitement
La condition est testée avant. Si fausse dès le début → 0 exécutions.

RÉPÉTER 1 fois min

# Algo Répéter Traitement Jusqu'à cond # Python (simulé) while True: traitement if cond: break
La condition est testée après. Exécution garantie au moins 1 fois.
Comparatif des boucles
CritèrePOURTANT QUERÉPÉTER
Nb répétitionsConnuInconnuInconnu
Test condition–AvantAprès
Min exécutions001
Exemple : somme de N entiers
n = int(input("N = ")) somme = 0 for i in range(1, n+1): x = int(input("x = ")) somme = somme + x print("Somme =", somme)
Ch.5 Les Sous-Programmes
5.1

Fonctions et Procédures

Fonction retourne une valeur

# Algo Fonction nom(params) : type Début Traitement Retourner résultat Fin # Python def nom(params): traitement return résultat
Exemple :
def somme(a,b): return a+b

Procédure pas de return

# Algo Procédure nom(params) Début Instruction1 ... Fin # Python def nom(params): instruction1 instruction2
Exemple : Permuter deux valeurs :
def permuter(a,b): return b,a

ModeNotationEffet

Portée des variables
Locale : déclarée dans le sous-programme → accessible uniquement dans ce sous-programme.

Globale : déclarée dans le programme principal → accessible par tous les sous-programmes.

Ch.6 Algorithmes de Tri et de Recherche
6.1

Tri par Sélection

Principe
  • Chercher le plus petit élément du tableau
  • Le placer en première position (échange)
  • Répéter sur le reste du tableau
  • Continuer jusqu'à ce que tout soit trié
À chaque étape, on sélectionne le minimum et on le place à sa bonne position.
Algorithme
Procedure tri_selection(@T:Tab, n:entier) Debut Pour i de 0 à n-2 faire posm ← i Pour j de i+1 à n-1 faire Si T[j] < T[posm] alors posm ← j FinSi FinPour aux ← T[i] T[i] ← T[posm] T[posm] ← aux FinPour Fin
6.2

Tri à Bulles

Principe
  • Comparer deux éléments voisins
  • S'ils sont mal ordonnés → les échanger
  • Sinon → ne rien faire
  • Répéter plusieurs passages jusqu'à stabilité
Les grandes valeurs remontent vers la droite comme des bulles dans l'eau.
Algorithme
Procedure tri_bulle(@T:Tab, n:entier) Debut Répéter test ← Faux Pour i de 0 à n-2 faire Si T[i] > T[i+1] alors aux ← T[i] T[i] ← T[i+1] T[i+1] ← aux test ← Vrai FinSi FinPour n ← n - 1 Jusqu'à (test = Faux) ou (n = 1) Fin
6.3

Tri par Insertion

Principe
  • Prendre le premier élément non trié
  • Le comparer aux éléments triés (droite → gauche)
  • Décaler les éléments plus grands vers la droite
  • Insérer à la bonne position
  • Répéter jusqu'à ce que toute la liste soit triée
Fonctionne comme lorsqu'on trie des cartes à jouer dans la main.
Algorithme
Procedure tri_insertion(@T:Tab, n:entier) Debut Pour i de 1 à n-1 faire aux ← T[i] j ← i TantQue (j > 0) et (T[j-1] > aux) faire T[j] ← T[j-1] j ← j - 1 FinTantQue T[j] ← aux FinPour Fin

6.5

Recherche Séquentielle

Principe
  • Parcourir le tableau élément par élément
  • Comparer chaque élément à la valeur cherchée
  • Si trouvé → s'arrêter
  • Sinon → passer à l'élément suivant
  • Fonctionne sur tout tableau (trié ou non)
Tableau trié ou non. On vérifie les éléments un par un.
Algorithme
Procedure recherche_seq(T:Tab, n:entier, x:entier) : booleen Debut Trouvé ← Faux i ← 0 TantQue (i < n) et (Trouvé = Faux) faire Si T[i] = x alors Trouvé ← Vrai Sinon i ← i + 1 FinSi FinTantQue Retourner Trouvé Fin
6.6

Recherche Dichotomique

Principe
  • Uniquement sur tableau trié
  • Comparer avec l'élément du milieu
  • Si égal → trouvé !
  • Si plus petit → chercher dans la moitié gauche
  • Si plus grand → chercher dans la moitié droite
  • Répéter jusqu'à trouver ou épuiser le tableau
⚠ Condition obligatoire : le tableau doit être trié avant d'appliquer la dichotomie !
Algorithme
Fonction recherche_dico(T:Tab, n:entier, x:entier) : booleen Debut Ind_Debut ← 0 Ind_Fin ← n - 1 Trouvé ← Faux TantQue (Ind_Debut ≤ Ind_Fin) et (Trouvé = Faux) faire Ind_Milieu ← (Ind_Debut + Ind_Fin) DIV 2 Si T[Ind_Milieu] = x alors Trouvé ← Vrai Sinon Si x < T[Ind_Milieu] alors Ind_Fin ← Ind_Milieu - 1 Sinon Ind_Debut ← Ind_Milieu + 1 FinSi FinSi FinTantQue Retourner Trouvé Fin
Comparatif des recherches
CritèreSéquentielleDichotomique
Tableau trié ?Non requisObligatoire
Nombre de comparaisonsAu plus nAu plus log₂(n)
EfficacitéLente (grands tableaux)Très rapide

Exemple visuel : recherche de 7 dans [1,3,5,7,9,11]
Étape 1 : Milieu = index 2 → T[2]=5 < 7 → chercher à droite

Étape 2 : Milieu = index 4 → T[4]=9 > 7 → chercher à gauche

Étape 3 : Milieu = index 3 → T[3]=7 = 7 → Trouvé !
